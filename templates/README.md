# Agent instruction templates

Five templates, one per file kind. Made by Ctrl Alt Delegate, a Hertect Consulting product.

| File | Kind | Where it goes |
|---|---|---|
| AGENTS.md | Rule, always on | repo root |
| CLAUDE.md | Rule, always on | repo root |
| copilot-instructions.md | Rule, always on | .github/ |
| cursor-rule.mdc | Rule or Skill | .cursor/rules/ |
| SKILL.md | Skill, used when needed | wherever your tool looks for skills |

Every rule has five lines: What, Applies to, Check, Owner, Reviewed. The Check line is the point. If you can't write it, the rule can't be verified and agents will drift from it without anyone noticing.
